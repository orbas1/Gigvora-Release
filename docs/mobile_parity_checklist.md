# Mobile Parity Checklist

This checklist maps core web flows to their mobile counterparts so we can validate parity against `logic_flows.md#5` and addon cross-journeys.

Status legend: **Complete** (mobile + web wired to live APIs), **Partial** (some flows missing), **Missing** (no mobile path yet).

| Surface | Web route(s) | Backend handler(s) | Mobile route/screen | Status | Notes |
| --- | --- | --- | --- | --- | --- |
| Feed hub + composer | `/` (authenticated timeline) | `MainController@timeline`, feed/comment/react routes in `routes/web.php` | Navigation tab fetched from `/api/navigation` renders `GigvoraFeedShell` | Complete | Stories rail, composer pills, recommendation lanes, ads, and utilities quick tools reuse the live feed/comment APIs. |
| Profile (timeline, media hub, saved) | `/profile`, `/profile/media-hub`, `/profile/photos`, `/profile/videos`, `/profile/save-post-list` | `MainController@profile`, profile media/feed endpoints in `routes/web.php` | Profile tab from nav config uses `GigvoraProfileShell` + media rail widgets | Complete | Mirrors hero + media tabs with the same media categorization, saved items, and utilities overlays. |
| Comments & reactions | `/post_comment`, `/get_comment/{postId}`, `/comment_reaction` | `ApiController@post_comment/get_comment/comment_reaction` | Feed post bottom sheet + thread UI inside `GigvoraFeedShell` | Complete | `GigvoraCommentsClient` calls the live Laravel endpoints for thread fetch, nested replies, reactions, and deletes with bearer tokens so composer/reply flows now mirror web without stubs. |
| Stories (capture/upload/editor) | `/create_story`, `/story_details/{story_id}` | `MainController@create_story`, `MainController@story_details` and `ApiController@create_story/stories` | Story rail + viewer using `GigvoraStoryRail`; upload hooks are wired to the same endpoints | Partial | Live upload/view backed; editing controls (filters/overlays/music, 4K→480p ladder) require audit to confirm parity with web composer. |
| Reels & long-form video | `/videos`, `/create_videos`, `/view_videos/{id}` | `ApiController@videos/create_videos/view_videos` | Media rail + video detail screens from `GigvoraMediaShell` | Partial | Upload/playback routes are live; need to validate caption/tag/location stage and scheduling options for long posts. |
| Live streaming + chat/donations | `/live` + room negotiation via `/roomName`, chat in `/chat_msg/{msg_thread}` | `ApiController@roomName` for live room, chat via `ApiController@chat_msg/chat_save/react_chat` | Interactive addon live shells from `_liveEventsRoutes` | Partial | Live join/chat are API-backed; donation goals/tiers and 4K/1080p/720p/480p ladder require verification on mobile clients. |
| Jobs – seeker | `/jobs`, `/jobs/{job}`, `/jobs/{job}/apply` | `JobController@index/show/apply` in Jobs addon web routes | Jobs addon routes exposed via `_jobsRoutes` when `JobsIntegrationOptions` enabled | Complete | Seeker menu and apply flow come from the jobs Flutter addon hooked to live API base URL. |
| Jobs – employer portal | `/employer/*` dashboard, ATS, interviews | `EmployerPortalController` web routes | Employer menu entries from `jobs.employerMenu` when `showEmployerMenu` is true | Partial | Mobile screens exist through addon routes; ensure employer flags/base URL are provided so ATS, billing, and interview tabs stay reachable. |
| Freelance marketplace | `/freelance/...` dashboards, gigs/projects/proposals | Freelance addon web routes under configurable prefix | Freelance Flutter addon routes registered via `_freelanceRoutes` | Complete | Buyer/seller dashboards, gig/project flows, and checkout routes align with the web Livewire controllers. |
| Interactive (webinars, networking, podcasts, interviews) | `/events/webinars`, `/events/networking`, `/events/podcasts`, `/events/interviews` | `WebinarPageController`, `NetworkingPageController`, `PodcastPageController`, `InterviewPageController` | Live addon routes from `_liveEventsRoutes` | Complete | Waiting, live, and replay flows are surfaced through the Flutter interactive addon with the same endpoints. |
| Ads (campaigns/creatives) | `/addons/advertisement/dashboard`, `/addons/advertisement/campaigns` | Advertisement addon Blade routes gated by `advertisement.enabled` | Advertisement Flutter addon routes from `advertisement_flutter_addon.buildAdsRoutes()` | Complete | Campaign/creative management mirrors the web dashboards when advertisement feature flag is enabled. |
| Talent & AI | `magicai` routes (workspace/launchpad/headhunters/volunteering) | MagicAI web routes under `routes/web.php` in the AI addon | Talent AI Flutter addon routes configured in `GigvoraAddonNavigation.routes` | Complete | Launchpad, headhunter, AI workspace, and volunteering screens reuse live APIs through `TalentAiApis.fromBaseUrl`. |
| Utilities quick tools + notifications | `/utilities/quick-tools`, `/notifications`, `/count_notification` | `UtilitiesQuickToolsController`, notifications handled in `ApiController@notifications` | `GigvoraQuickToolsClient` → `GigvoraQuickToolsPanel`; notification drawer routed from nav config | Partial | Quick tools are live; ensure push/notification registration and offline badge sync are mirrored in Flutter. |
| Navigation & settings | `/api/navigation`, `/settings/page/view` | `NavigationController@index`, `CustomUserController@all_settings_view` | `GigvoraNavigationClient.fetch` hydrates tabs/drawer | Complete | Role-aware tabs/drawer mirror the web IA; settings entries load via shared config. |
| Deep links & routing | Incoming links map to feed/profile/jobs/freelance/live routes | Laravel web routes (`routes/web.php`, `routes/custom_routes.php`) | Flutter `onGenerateRoute` uses `GigvoraAddonNavigation.routes` + nav API | Partial | `GigvoraDeepLinkRouter` now resolves cold-start URIs into nav/addon routes (profile, jobs, freelance, live, media) using the live nav config; needs QA on edge-case paths. |
